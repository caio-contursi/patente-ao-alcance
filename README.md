# Patente ao Alcance

Repositório de planejamento e materiais iniciais do projeto de extensão **Patente ao Alcance**.

## Documento inicial

- [Planejamento completo em Markdown](docs/planejamento-do-projeto.md)

O planejamento organiza seis módulos, entregas, cronograma, responsabilidades e critérios de conclusão para Pedro Bartkevihi, Caio Contursi e Enzo Paulino. A carga definida é de 150 horas por integrante (450 horas de equipe), com 20 horas semanais por pessoa e conclusão prevista para 23/12/2026.
